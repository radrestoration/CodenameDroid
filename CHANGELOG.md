# Changelog

## v1.0.0

First full release with many bug fixes and speed ups. 

- C64-native rewrite of Codename Droid with a wide, smoothly scrolling view.
- Includes the loading screens and game on one D64, plus a standalone game PRG.
- PAL and NTSC support, keyboard and provisional joystick controls.
- Includes lift transitions, the wrist terminal, maps and a SID sound driver.
